Wyoming Groundwater Rights Lookup

Wyoming's own water-rights system (e-Permit) requires a login with no public access. This instead uses a public dataset the Wyoming State Geological Survey hosts, sourced directly from the State Engineer's Office — real permitted wells and springs, each already combining the water-right record (priority date, status, use) with well construction detail (depth, water level) in one record.

This covers groundwater rights (wells and springs) only — Wyoming's surface-water rights (ditches/canals diverting from a stream) and reservoirs aren't available outside the state's login-walled system, so they won't show up here.

What this is: live data pulled through this project's own backend from a public Wyoming State Geological Survey service (the "Groundwater Atlas"), sourced directly from the State Engineer's Office — Wyoming's real permitted groundwater wells and springs, each record combining the water right (WR number, priority date, status, use) with well construction detail (total depth, static water level) already on file.
